【Yoko 1-10天自然衔接话题链 V5.1｜中日双语｜主话题+3~4句延伸｜保留见面与未来买房主线】

【整体说明】
每个主话题下面放3～4句可自然延伸的话术。
不是每句都提问，而是混合：
回应 / 共鸣 / 自己分享 / 轻度延伸 / 偶尔提问。

一个主话题聊够后，再用最后一句自然过渡到下一个主话题。

后半段明确保留并逐步加强：
见面期待
→ 第一次见面
→ 吃饭 / 咖啡
→ 见面后的感觉
→ 未来生活
→ 想住哪里
→ 理想生活环境
→ 公寓 / 独栋
→ 两个人理想的生活空间
→ 旅行与未来日常
